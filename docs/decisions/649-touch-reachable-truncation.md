# Cut-off text keeps a way in on touch (#649)

- **The rule is three named ways in, and no fourth.** Every `data-truncate` element names, as the attribute's value, how its whole value is reached without hover: `expand` (a press on a toggle with `aria-expanded` in it opens the whole value wrapped inline), `detail` (it is, holds or sits inside a link that opens the view where the whole value shows), or `copy` (a Copy button beside it copies the whole value). A bare `data-truncate` or any other value is a title-only truncation and fails. This was chosen over unwrapping everything on coarse pointers alone because it keeps the compact rows on touch too, works with a mouse and a keyboard as well, and each way can be checked in the page rather than trusted from the stylesheet. Where none of the three fits, the text wraps and is not truncated. Written in `ui/README.md` (Cut-off text) and in the header of `ui/scripts/layout-check.mjs`; applies to every current and future `data-truncate` in Toil UI.
- **The layout check verifies the way, not just the word.** `inspect()` in `ui/scripts/layout-check.mjs` fails a `truncate-touch` finding when the named way is not in the page: no toggle for a cut `expand`, no link for a `detail`, no Copy button for a `copy`. An `expand` that cuts nothing in its box needs no toggle yet, since it hides nothing there; the check runs at 375, 768 and 1440px, so a chip is held at the width where it does cut. `inspect` is exported so `ui/test/truncate-touch.test.ts` can hold the check itself without a browser.
- **Each current use takes the lightest way that was already almost there.** Path and Url were already `copy` and only name it. A ticket chip with a link and a Classify sort-row head (whose item link it holds) are `detail`. The stand-up chips, the Toil project bar's description, a stand-up card's account name, an approval card's item titles and a ticket chip with no link are `expand`: the approval title especially stays in its card, because that card is where a person approves it, rather than sending them to the item and back. A stand-up chip grows its toggle only when its folded form hides something, or holds enough text that a phone's row would cut it, so chips that hide nothing stay uncluttered.
