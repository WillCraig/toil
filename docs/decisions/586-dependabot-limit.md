# Room for Dependabot's grouped pull requests (#586)

- **The npm entry's `open-pull-requests-limit` goes from 5 to 10.** After #606 merged, Dependabot's npm run built the `shipped`, `tooling` and `majors` pull requests, and none of them opened: nine npm pull requests from the earlier grouping (#593, #594, #598 to #604) were still open and already past the limit of 5. The Actions entry shows the same rule: its group pull request (#607) opened only once one of its three older pull requests had closed, and Dependabot then closed the other two as superseded by it.
- **Raised rather than closing the old pull requests by hand.** Closing a Dependabot pull request by hand tells it to skip that release, so a group could leave the package out until its next release. With room under the limit, the groups open and Dependabot closes what they supersede itself, which is what it did for the Actions pull requests.
- **10 never binds in normal running.** The npm groups make at most three version pull requests a week; the limit only has to stay above what's left open while a new group replaces older ones. Security updates have their own fixed limit and are not counted here.
- **Not changed:** the typescript 7 update fails in the `majors` group ("Error while updating peer dependency": `typescript-eslint` 8.72.2 admits TypeScript only below 6.1), so Dependabot marks the npm run as failed while still opening the group without it. Ignoring TypeScript majors would hide that, so it is left to show until `typescript-eslint` supports TypeScript 7.
